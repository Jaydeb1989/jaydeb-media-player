JAYDEB BARUA MEDIA PLAYER — PWA files

To install as an app on Android:
1. Upload all files in this folder to a web host that supports HTTPS (for example, GitHub Pages or Render static site).
2. Open the published HTTPS website in Chrome on your Android phone.
3. Tap Chrome's three-dot menu and choose "Install app" or "Add to Home screen".
4. Confirm. The player icon will appear on your phone.

Important:
- Keep index.html, manifest.webmanifest, sw.js, and the icons folder together.
- The installable app needs to be hosted on HTTPS; opening index.html directly from file storage will not install it as a PWA.
- Audio/video files selected in the player stay on your device and are not uploaded.
